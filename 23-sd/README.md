# 23-sd

嘉立创·庐山派 K230-CanMV 板载 **TF 卡**。控制器是 **SD1**（`0x91581000`），脚 **io54–io59**、`IO_SEL=2`。命令顺序参考 `riscvboot/drivers/sd/sd.c`（CMD0/8/ACMD41/2/3/7、ACMD6、CMD17/24），主机复位、3.3 V、约 400 kHz 和 74 个时钟在本课里补上。

扇区 0 只读。`w` 把当前图案写到当前 LBA，并留在卡上，再用 `2` 自己读。图案是 `pat, pat+1, …`，每 256 回绕；`[` / `]` 改首字节，默认 `a0`。`3` 跳到 LBA 256（GPT 表之后、常见首分区 LBA 2048 之前）。写之前会复位 DAT，避免读完后的第一次 `CMD24` 把 FIFO 清掉。

```bash
cd 23-sd && make
../cp_bin.sh 23-sd
```

加载 `bootsys.bin` @ `0x80200000`。先插好 TF 卡。

## 菜单

```
1  初始化（pinmux + 识别卡）
2  读当前 LBA（启动后是 0；看 55 AA）
3  跳到 LBA 256 并读
+ / - / 0       换 LBA 再读
[ / ]           图案首字节 -1 / +1
w  当前 LBA 写入图案并留下（LBA 0 拒绝）
4  dump io54–59
h  帮助
```

`1` 成功时 `clk=0x000efa07`、`run=0x000e0807`。`w` 得到 `PASS wrote` 后，`2` 的前 16 字节应与刚打印的图案一致。
